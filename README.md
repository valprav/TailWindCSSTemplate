# TailWindCSS Template

This project provides a simple Next.js starter styled entirely with Tailwind CSS. It includes reusable components like a navigation bar, hero section, story generator wizard, feature grid, testimonials, pricing table, FAQ accordion, and footer. Additional examples include a user profile form, story list, and story preview card.

## Included Components
- Navigation bar
- Hero section
- Story generator wizard
- Feature grid
- Testimonials
- Pricing table
- FAQ accordion
- User profile
- Story list
- Story preview

The template includes seven selectable color palettes and uses the "Quicksand" font for a fun feel.

## Getting Started
1. Install dependencies
   ```bash
   npm install
   ```
2. Start the development server
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` to see the main page.
4. Open `http://localhost:3000/demo` to view each component on a single page and test different color palettes.
5. The demo page also showcases the story generator wizard.

Available palettes are **Sky**, **Forest**, **Sunset**, **Berry**, **Ocean**, **Candy**, and **Lemonade**. Use the selector on the demo page to switch between them.
